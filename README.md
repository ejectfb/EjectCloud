# EjectCloud

Свой облачный диск с Telegram-аутентификацией. Закинул на сервер — и у всей семьи/команды есть файлопомойка с нормальным веб-интерфейсом.

Работает поверх HTTPS (сертификат самоподписанный, генерится на месте), пользователи входят через Telegram-бота. Никаких регистраций с паролями — кинул ссылку, человек залогинился, готово.

## Что умеет

- Загрузка файлов перетаскиванием, папки, переименование, перемещение
- Корзина — удалил случайно, можно восстановить
- Шаринг файлов: публичная ссылка с настраиваемым сроком жизни
- Предпросмотр текста и стриминг видео прямо в браузере
- Скачивание целых папок архивом
- Квоты на пользователя — чтобы никто не забил весь диск
- Админка: список пользователей, квоты, сброс паролей, настройка Telegram-бота

Из коробки: rate-limiting, защита от Slow Loris, HSTS и прочие мелочи, чтобы не положили за пару запросов.

## Запуск

Нужны Java 21, Maven и Python (для генерации сертификата).

```
python generate_keystore.py
mvn spring-boot:run
```

### Первый вход

При первом запуске (если папка `Data` пустая) создаётся админ:

```
admin@admin.admin / admin
```

Пароль не совпадает с email, но логин-страница всё равно заставит сменить пароль и заполнить профиль.

Дальше админ идёт в админку (вкладка «Пользователи» → «Создать пользователя»), указывает email, никнейм, имя и квоту. Сервер создаёт учётку, где пароль равен email.

Пользователь заходит на `https://localhost:8443`, вводит свой email и как логин, и как пароль. Система сразу просит придумать нормальный пароль — и после этого он в приложении.

Telegram пользователь привязывает сам, уже изнутри: Настройки → вкладка Telegram → получить код у бота командой `/code` → ввести код в поле. Это опционально, нужно только для кнопки «Отправить в Telegram».

## Telegram-бот

1. Создайте бота через [@BotFather](https://t.me/BotFather), скопируйте токен
2. Узнайте свой Chat ID через [@userinfobot](https://t.me/userinfobot)
3. Пропишите токен в `application.properties` или настройте через админку

После этого бот сможет выдавать ссылки для входа (`/link`) и ссылку в админку (`/admin`).

## Структура

```
src/main/java/org/ejectfb/ejectcloud/
    controller/   — REST-ручки
    service/      — логика (файлы, пользователи, JWT, Telegram)
    model/        — модельки данных
    config/       — Spring-конфиги (безопасность, фильтры, rate-limit)
src/main/resources/
    static/       — фронтенд (ванильный HTML/CSS/JS)
Data/             — пользовательские файлы (в гитигноре)
config.properties — генерится при первом запуске
keystore.p12      — SSL-сертификат (генерится скриптом)
```

## Пара замечаний

- По умолчанию квота на пользователя — 1 GB, меняется в админке
- Сертификат самоподписанный, браузер будет ругаться. Для продакшена замените на нормальный
- Все пароли и соль лежат в `config.properties` — не светите их наружу, файл уже в `.gitignore`

## Сборка

```
mvn clean package
```

Собранный jar со всем необходимым внутри.
